# Asar

**Asar** is an AI-powered social media script generation platform built for content creators. Instead of simply generating generic AI-written scripts, Asar analyzes viral content within a creator's specific niche to identify trends, hooks, content structures, pacing, and other patterns that are currently working.

The platform combines **niche intelligence, creator-specific style analysis, and AI models such as GPT, Gemini, and Claude** to generate original, ready-to-shoot scripts. Creators can receive shot-by-shot directions, hooks, on-screen text, CTAs, captions, and other production guidance in **Hindi, Hinglish, or English**.

### Core Workflow

**Analyze → Understand → Create → Publish → Measure → Learn**

Asar continuously analyzes relevant content and creator performance to improve future recommendations, with the goal of giving individual creators access to the kind of scripting and content intelligence usually available to larger creator teams.
